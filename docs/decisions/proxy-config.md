# API トークンなどの秘匿

## 現行の方針

- 秘密は `setProxyConfig` に、秘密でない目次は `setConfig` に分けて保存する
- auto-numbering はプロキシ設定を自分で持ち、秘匿のための汎用プラグイン `api-proxy` も別に作る
- 先に auto-numbering で作り、保存の処理を共有パッケージに移してから `api-proxy` を作る
- 守れるのは秘密の値だけで、使えることは隠せない。api-proxy は既定では URL とメソッドで絞らず、トークンの権限に任せる。絞りたいときは、管理者が URL とメソッドを具体的にする
- api-proxy の設定画面は、kintone の REST API と外部の API を同じ形の行（接続先）で登録する

詳細は [proxy-config.md](../proxy-config.md)。

## 判断履歴

### 2026-11-23 auto-numbering への組み込みと汎用プラグインの両方を作る

- 背景: auto-numbering は API トークンを `setConfig` に平文で保存しており、アプリを使う全員がブラウザから読める。また、JS カスタマイズでは秘密を置く場所が無い（`kintone.proxy` にはプロキシ設定が無い）
- 検討した選択肢: (a) auto-numbering に組み込むだけ (b) 組み込みと汎用プラグインの両方 (c) 汎用プラグインだけを作り、auto-numbering もそれを使う
- 決定: (b)。外部 API を含め、JS カスタマイズからも秘密を使いたい
- 却下した理由: (a) は JS カスタマイズの用途を満たさない。(c) は auto-numbering を使うのに別のプラグインの導入と設定が要り、プラグイン ID の受け渡しも必要になる

### 2026-11-23 api-proxy の設定画面は、kintone と外部の API を同じ形の行で登録する（下の2つの判断を覆す）

- 背景: kintone タブで「許可する操作」を選ばせると、API の一覧（公式で53件）をプラグインが持ち、kintone に API が増えるたびに直す必要がある。また、最初に挙げた7つの操作には根拠が無く、トークンで使えない API も含んでいた
- 決定: 既定では URL とメソッドで絞らず、トークンの権限に任せる（設定画面で、必要な権限だけにし、アプリ管理の権限は付けないよう案内する）。絞りたいときは、管理者が URL（例：`/k/v1/records.json`）とメソッドを具体的にする。そうすると kintone タブと外部タブの違いが「URL の組み立て・ヘッダー名・トークンのつなぎ方を助けるか」だけになるので、タブを分けず、同じ形の行（URL・メソッド（複数）・ヘッダー・本文・メモ）にし、kintone の分はボタンで補う。ヘッダーと本文は JSON ではなく、キーと値の行で入力する
- 却下した理由: API の一覧から選ばせる案は、保守の手間が大きい。タブを分ける案は、絞り方を URL とメソッドで表すなら、2つの入力の形と、外部 API の URL が kintone のトークンを上書きしないための検証を持つ分だけ複雑になる。複数アプリのトークンをプラグインがつなぐ利点は、1つの値にカンマ区切りで書く案内と、9個までの検証で補える

旧判断（覆した）: 2026-11-23「api-proxy は kintone REST API と外部 API をタブで分ける」（kintone タブはアプリごとの行で入力し、プラグインがトークンをつなぐ）

### 2026-11-23 設定画面で秘密を読み直し、ふだんは見せない

- 決定: `getProxyConfig` で読み、フォームに戻す。api-proxy は、ふだんはキーだけを出し、値は「編集」のダイアログの中でだけ見せる（JSON でまとめて書くため。画面の共有などでは、ダイアログを開かなければ値は映らない）
- 却下した理由: 「設定済み」とだけ出して入力時に上書きする形は、一部だけを直せない。設定画面を開けるのはアプリの管理者だけなので、ダイアログで見せても漏れる範囲は変わらない
- 経緯: 最初は伏せ字の欄と表示の切り替えにしたが、ヘッダーと本文の値を JSON でまとめて書く形にしたので、ダイアログで見せる形に変えた

旧判断（覆した）: 2026-11-23「kintone タブでは、行ごとに許可する操作を選ばせる」（選んだ操作の URL とメソッドだけを保存する。API の一覧を持つ必要があり、上の判断で覆した）。その前の「kintone タブではメソッドを選ばせない」も、メソッドを行ごとに選べるようにしたので覆した
