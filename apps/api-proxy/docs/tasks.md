# API プロキシ設定プラグイン — 残タスク

> **最終更新**: 2026-11-23
> **参照**: [design.md](./design.md)

## 実機で確かめること（2026-11-23 に確認済み）

- [x] 接続先を保存し「アプリを更新」したあと、レコードの画面から proxy を呼ぶと、kintone の REST API と外部の API に値が付く
- [x] 設定画面を開き直すと、ヘッダーとデータが戻る（本文の数値を含む）
- [x] 接続先を消して保存すると、その組の値が付かなくなる
- [x] `getConfig` とエクスポートしたファイルに、値が入っていない
- [ ] 接続先を無効にして保存し、開き直すと値が残っている（`https://api-proxy-disabled.invalid/…` を kintone が保存・読み込みできる）。有効に戻すと、値が付く

## 必要になったら

- [ ] ファイルのアップロード（`kintone.plugin.app.proxy.upload`）で、保存した値が付くかを確かめ、使い方に書く
