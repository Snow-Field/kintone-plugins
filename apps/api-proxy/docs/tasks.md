# API プロキシ設定プラグイン — 残タスク

> **最終更新**: 2026-11-23
> **参照**: [design.md](./design.md)

## 実機で確かめること

- [ ] 接続先を保存し「アプリを更新」したあと、レコードの画面から proxy を呼ぶと、kintone の REST API と外部の API に値が付く
- [ ] 設定画面を開き直すと、ヘッダーと本文の値が戻る（本文の数値・真偽を含む）
- [ ] 接続先を消して保存すると、その組の値が付かなくなる
- [ ] `getConfig` とエクスポートしたファイルに、値が入っていない

## 必要になったら

- [ ] ファイルのアップロード（`kintone.plugin.app.proxy.upload`）で、保存した値が付くかを確かめ、使い方に書く
